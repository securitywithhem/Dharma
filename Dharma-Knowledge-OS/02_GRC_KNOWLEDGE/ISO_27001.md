# ISO 27001

ISO/IEC 27001:2022 is the international standard for an Information Security Management System (ISMS) — a systematic approach to managing sensitive company information via risk assessment and a defined set of controls (Annex A, ~93 controls across 4 themes: organizational, people, physical, technological).

Certification requires: a documented ISMS, a risk assessment/treatment process, implemented Annex A controls (or a justified exclusion via the Statement of Applicability), and a successful external audit (Stage 1 + Stage 2).

## In Dharma

- Tracked as a `Framework` row (name: "ISO 27001:2022"), with each Annex A control represented as a `Control` row scoped to a `domain` (e.g. "Logical Access"). See [[Database_Design]].
- Control status lifecycle: `NOT_STARTED` → `IN_PROGRESS` → `COMPLIANT` / `NOT_APPLICABLE`.
- Cross-walked to SOC 2 via `ControlMapping` — e.g. **SOC2 CC6.1 ↔ ISO27001 A.9.2.1** (both cover logical access provisioning), so evidence uploaded once can satisfy overlapping controls in both frameworks. This is the concrete example cited in the schema doc.
- Framework import available via the Marketplace (`MarketplaceItem`) rather than only manual seeding — see [[User_Journeys]] Journey: Marketplace Import.
