# 99_AI_MEMORY

This folder is a session-continuity checkpoint for any AI agent (Claude Code or otherwise) working on Dharma. Read [[status]], [[progress]], and [[decisions]] here **before** writing code in a new session.

- **[[status]]** — current state snapshot: what's built, what's pending, known gaps.
- **[[progress]]** — append-only log of sessions and what changed (mirrors [[Progress_Log]] in `05_DEVELOPMENT`, kept separate so an agent doesn't have to read the whole dev folder just to get oriented).
- **[[decisions]]** — append-only log of significant decisions (mirrors [[Decisions]] in `05_DEVELOPMENT`).

For deep technical/product context beyond a quick status check, go to [[Dharma_Master_Context]] first, then drill into `04_TECHNICAL` or `03_PRODUCT` as needed.
